# App Factory (com.web2apk.studiopro)

تم توليد هذا المشروع بواسطة **Web2APK Studio Pro**.

## طرق استخراج ملف الـ APK الموقّع:
1. **تلقائياً عبر GitHub Actions:** ارفع هذه الملفات إلى مستودع GitHub وستجد ملف `.apk` جاهزاً في قسم **Releases** و **Actions** خلال دقيقتين.
2. **محلياً عبر Android Studio:** افتح هذا المجلد واضغط **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
